# 그림책 미술키트

그림책과 연계한 미술 프로그램, 수업 일정, 주차별 키트 준비물을 한 화면에서 챙기는 선생님용 앱이에요.

- 프로그램 34개: 그림책, 활동 순서, 준비물, 교사 팁
- 재료별·조합 검색, 이번 달 그림책
- 수업 만들기: 날짜 자동 생성, 주차별 프로그램, 주차별 재료 체크
- 키트 준비 목록: 아이 수에 맞춰 준비물 합산
- 수업 계획서를 워드(.docx) 파일로 내보내기 (한글에서도 열려요)

## 이 웹사이트 버전에서 알아 둘 점

- 수업 일정과 체크한 재료는 **지금 쓰는 브라우저에만** 저장돼요. 다른 기기나 다른 사람과는 공유되지 않아요.
- 프로그램 추가·수정·사진 올리기는 Claude 앱 버전에서만 할 수 있어요.

파일은 `index.html` 하나로 되어 있어요.

## 안드로이드 앱(APK)

[미술키트 1.7 APK 받기](download/artkit-1.7.apk) · 받은 파일을 열어 설치하세요. "출처를 알 수 없는 앱" 허용이 필요할 수 있어요.
인터넷 없이 열리고, 수업 계획서는 휴대폰 다운로드 폴더에 저장돼요.

## 홈 화면에 웹앱으로 설치하기

- **안드로이드(크롬)**: 사이트를 열고 홈의 ‘앱으로 설치하기’를 누르거나, 메뉴(⋮) → ‘앱 설치’
- **아이폰(사파리)**: 아래쪽 공유 버튼 → ‘홈 화면에 추가’

설치하면 홈 화면 아이콘으로 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷이 없어도 열려요.
